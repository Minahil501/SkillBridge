SkillBridge

Employability score & career-path prediction — technical summary
Minahil Kamran
2026
Predicts a student's employability score (0–100) and recommends one of six career paths from a 33-field academic / technical / soft-skill / activity profile, using an ensemble ML pipeline (scikit-learn + XGBoost) served through FastAPI, with real per-prediction SHAP explainability, confidence across all six careers, and an LLM chat assistant for follow-up guidance — presented through a React dashboard.

Key Features

  • Real confidence, not just a label — soft-voting exposes probability across all 6 careers, plus an uncertainty range on the score from base-learner disagreement.
  • Genuine explainability — SHAP TreeExplainer attribution (not a canned explanation) alongside population z-score comparison, toggleable in the UI, plus a SHAP waterfall chart.
  • Bias-audited — Gender was originally an input feature; audited, found to contribute zero predictive value, and removed — retrained metrics identical to 4 decimal places.
  • LLM chat assistant — free-tier Hugging Face model answers follow-up questions grounded in the actual prediction.
